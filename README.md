1. 外部サーバーへの送信

夢の入力文字を外部のサーバーへ送信する処理（fetch や XMLHttpRequest 等による外部送信コード）はありません。

2. ブラウザや外部への保存

localStorage や Cookie への保存処理はなく、ブラウザや外部ストレージへの保存は行われません。入力した文字はページを開いている間だけ画面上に残り、最初の画面に戻すと消去されます。
